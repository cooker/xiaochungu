# PinMe
这个叫 PinMe 开源项目的主要优势是：
免费：0 元成本，传统方式仅域名和服务器一年约 300 元。
极速：30 秒上线，传统部署需要 30 分钟或更久。
稳定：依托 IPFS 网络，内容分布式存储，不易宕机，传统服务器挂了就无法访问。
便捷：支持两种方式上传网页拖拽零命令和命令行的方式。
```shell
npm install -g pinme
pinme upload <folder/file-path>
```
